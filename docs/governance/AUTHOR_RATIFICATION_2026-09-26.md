Q6. C1 scoring (this is also CC-1)

Decision:

Primary: mean page-span IoU over HOLDOUT documents whose Gold says MD&A is present.

Weighting: document-weighted. With 9 issuers × 6 documents each, this equals issuer-weighted unless eligibility removes documents unevenly. Issuer-weighted is reported as a sensitivity.

Gold says absent: excluded from the IoU mean and scored only in a separate presence endpoint (2×2). Never IoU = 1.

No prediction: IoU = 0, counted as a failure.

Invalid prediction (not integers, start > end, or outside the page count): IoU = 0, counted as a failure, reported by type.

QUARANTINE: IoU = 0 in the primary. The quarantine rate is also reported as abstention.

Ambiguous Gold: excluded from the primary with its count reported; included in a sensitivity analysis against admissible spans, labelled optimistic. The AMBIGUOUS state must be assigned before any system output for that document is viewed.

Secondary: complete-case accuracy, labelled conditional, with coverage reported.

This requires the formal Level C amendment (C1-D1) at the Gold freeze. The closeout records the decision; it does not implement it.

Author: ACCEPT — "My main score measures how accurately ARPipe finds the MD&A page span. Failures count as failures instead of disappearing. Documents with no MD&A are handled separately. Ambiguous Gold can only be excluded if it was declared ambiguous before seeing ARPipe's answer."
